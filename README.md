## Project Repositories

| Project | Description |
|---|---|
| [AI Coffee Recommendation Engine](https://github.com/Akanksha-Nakati/AI-Coffee-Recommendation-Engine) | Built an end to end recommendation system using PySpark on Databricks with medallion architecture (Bronze/Silver/Gold) → Scraped Starbucks/Dunkin menus and Reddit communities (r/starbucks) via PRAW to extract real drink customization patterns → Indexed embeddings with ChromaDB/FAISS using Sentence Transformers → Deployed conversational Streamlit interface for personalized recommendations |
| [Agentic AI Trading Assistant with RAG](https://github.com/akanksha-nakati) | Designed a multi agent trading assistant using LangChain and Gemini API → Built a FAISS-backed RAG pipeline to retrieve financial context for investment Q&A → Integrated real time query routing across retrieval and web search agents |
| [Analytics Data Warehouse Platform](https://github.com/Akanksha-Nakati/Analytics_Data_Warehouse_Platform) | Designed a Snowflake + Databricks data warehouse on GCP with star schema architecture → Orchestrated PySpark transformation pipelines with Airflow → Visualized KPIs in Tableau with SQL validation for data accuracy |
| [Ad Budget Forecasting AI System](https://github.com/Akanksha-Nakati/AI-Powered-Ad-Assessment-Platform) | Built a RandomForest based forecasting model for ad budget optimization → Integrated RAG pipeline with Streamlit interface for interactive budget scenario planning → Containerized with Docker for reproducible deployment |
| [Rare Beauty UX & Marketing Analytics](https://github.com/Akanksha-Nakati/User-Centered-Product-Design-and-Marketing-Optimization) | Conducted end to end UX research and built a MySQL ETL pipeline for customer and product data → Created Tableau dashboards for marketing funnel analysis → Designed a Figma prototype for improved product discovery experience |
